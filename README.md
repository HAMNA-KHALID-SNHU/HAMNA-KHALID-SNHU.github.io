# Briefly Explain The Work That You Did On This Project

Throughout this capstone, I revisited software projects completed during previous courses and enhanced them using the technical knowledge and professional practices developed throughout my Computer Science degree.

The Software Design and Engineering enhancement focused on improving the **CS-340 Grazioso Salvare Animal Rescue Dashboard** by implementing structured logging, enhanced exception handling, improved validation, refactored code organization, and usability improvements.

The Algorithms and Data Structures enhancement expanded the **CS-300 Advising Assistance Program** through graph-based prerequisite modeling, Directed Acyclic Graph (DAG) implementation, Depth-First Search (DFS) cycle detection, prerequisite validation, and topological sorting to generate suggested course completion sequences.

The Databases enhancement further strengthened the Grazioso Salvare dashboard by improving MongoDB CRUD functionality, implementing aggregation pipelines, introducing compound indexing, improving validation and exception handling, and optimizing database queries to improve efficiency and maintainability.

Throughout the capstone, I also completed a comprehensive code review, developed enhancement narratives, created a professional self-assessment, and published a GitHub Pages ePortfolio showcasing the completed work.
